# Household absence locks

Latest user requirement, 14 October 2026: a house locks whenever no living, awake member of the owning household is inside. This includes an empty home and a home containing only sleeping residents, at any time of day. The routine lock releases when a resident inside wakes or an awake resident returns. For example, a father waking early releases the routine lock; when he leaves while everyone else sleeps, it locks again. This supersedes fixed night-to-morning routine locking and the earlier rule that any resident presence unlocks the house. Use authoritative scheduled/persistent location and sleep state, not whether an actor happens to be loaded or visible. Residents travelling home have not returned until they cross the home threshold. A family with no living members follows the separate vacancy/repopulation rules rather than unlocking because the household is empty.

Entering the locked, absent household is trespassing when a surrounding NPC witnesses the entry. Use nearby visibility and the bounded citizen report system, followed by finite guards travelling from actual positions. Do not grant guards omniscient knowledge or invent immediate responders. An unwitnessed entry remains unreported until independently discovered. Legitimate ownership or explicit access permission must be respected; merely having a quest in the building is not automatic permission.

Persist lock changes through transitions and save/load. Departure, arrival, sleeping and waking can change the routine lock independently of clock time. Preserve explicit security and quest locks, but replace fixed routine night locking with this occupancy rule. An awake resident does not automatically grant permission to enter. Distinguish resident access, player access, native quest-required locks and the mod's routine lock so native door state is not permanently corrupted.

Acceptance: all residents away at noon; only sleepers remain; first resident wakes; that resident leaves while others sleep; another wakes; awake resident returns; temporarily unloaded actors; player crosses town boundaries; reload while absent/asleep; witnessed versus unseen entry; nearby guard versus distant/no guard; pending alarm survives transition; player-owned home; explicit permission; quest destination; deceased family/vacancy. This requirement is documented, not implemented yet.

# Receipt-grounded action wording implementation plan

> **For agentic workers:** Implement the approved architecture's display-only renderer with separate Core, runtime and native-probe ownership. Parent verifies and promotes only after native integrity checks.

**Goal:** Replace generic spoken action acknowledgments with contextual English wording, without changing authoritative outcomes, losing turns or granting execution authority to prose.

**Architecture:** A typed render request binds the exact player turn, immutable snapshot and verified ConversationActionReply. It converts into a non-social rephrasing request with structured receipt facts and restricted voice context; canonical `NpcText` is not prompt content. Native state remains authoritative. Pending wording owns one reply stage. A valid exact duplicate gets one rephrase attempt with the previous NPC wording as data and a distinct cache key. Invalid/empty output or a second duplicate becomes the system-origin unavailable row, not NPC speech. Normal close/save flushes canonical `NpcText` exactly once before memory capture, except when it would repeat the last NPC reply, which becomes unavailable. Load/reset discards pending work across epochs. No transcript/archive rewrite or second spoken turn is used.

**Tech stack:** Existing Core DialogueRequest/LocalDialogueCompletion, native action reply receipt, async LocalDialogueClient and owned native runner.

**Spec:** `docs/superpowers/specs/2026-10-20-npc-agent-architecture.md`, section 8. The user has authorized roadmap implementation and explicitly forbids regex/phrase interpretation.

## Deliberate boundaries

Initial wording concerns the verified outcome/status; the receipt has no verified destination/item/price details, so the renderer must not infer those from the player request. Per-step rich fact rendering can extend the typed contract later. Free-form text can still be semantically wrong; structural validation cannot certify its truth, and no regex word lists or perfect-model gate are introduced. Native receipts and effects remain independently authoritative. All gameplay durations use in-game time; renderer service deadlines are instrumentation only.

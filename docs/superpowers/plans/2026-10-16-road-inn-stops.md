# Intermediate road inn stops

**Goal:** Long journeys stop at real intermediate inns, then continue to the original destination and finally home with the same resident identity.

**Architecture:** Keep one resident-owned trip. Add ordered stops along its surveyed road, each with a settlement and a normal local inn visit. Derive absolute road/visit timing together. A planned visit does not pay for a room: existing keeper, inventory, crime and first-come admission rules remain authoritative.

**Constraints:** One resident per bed; children do not travel. No duplicate home resident, invented beds, teleporting or road shortcuts. Existing saves retain their original timing when no road stops exist. Use the normal mod API and existing native serializer. Implement in this worktree without agents or unrelated cleanup.

The road timeline replaces the covered regional segments with the local visit duration. Schema 17 is required for these stops; schema 16 single-join trips migrate unchanged. Stop ranges cannot overlap, primary destinations still return to their join, and this representation does not itself certify street or wilderness clearance.

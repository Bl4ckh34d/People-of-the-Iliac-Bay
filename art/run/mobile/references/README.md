# Verified running reference

Source: https://opengameart.org/content/randytaylers-3d-man-running-animations-fixed
Original creator: RandyTayler. Corrected frame order: thealeks, 11 March 2024.
Direct source PNG: https://opengameart.org/sites/default/files/spritesheet_50x50_fixed.png
License declared on the source page: CC0.

The downloaded original is 250 × 400 pixels, RGBA. The author's grid is 50 × 50 pixels. Visual inspection confirms eight direction rows and five columns: one idle pose followed by four running frames. Therefore the running portion is exactly eight directions × four frames (32 images). The first column is not part of the run loop.

This is a normal-proportioned male in an orange jumpsuit rendered from a 3D model. The page tags it isometric. The profiles appear close to eye level; the front and quarter views are somewhat elevated. It is a useful limb-phase and occlusion reference, not a Daggerfall palette, costume, resolution or camera match.

Important: the coherent chronological phases do not implement strict per-frame arm lead A–B–A–B. Enlarged profile inspection shows adjacent contact/recovery frames retaining the same arm lead. Do not blindly reorder these four frames merely to force ABAB. This is a reference-search result, not a new approved animation contract.
